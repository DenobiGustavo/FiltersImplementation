# Filtros de Imagem com Pillow

## Visão Geral

Este repositório contém implementações de diversos filtros para manipulação e processamento de imagens, utilizando a biblioteca [Pillow](https://python-pillow.org/). O objetivo é oferecer uma coleção de exemplos práticos de filtros que podem ser aplicados a imagens para efeitos visuais, análises ou ajustes.
